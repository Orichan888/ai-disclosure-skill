# ai-disclosure

A skill for managing AI-use disclosure and provenance across platforms — for creators who use AI in text, images, video, and audio.

## What it does

When you publish AI-assisted work, every platform asks for disclosure differently: Kakuyomu's AI tags, YouTube Studio's altered-or-synthetic-content declaration, Etsy's AI-use disclosure in listings, Instagram/TikTok's AI-generated labels. Forgetting a disclosure can mean limited reach, demonetization, or removal. Getting it wrong costs reader and buyer trust.

This skill keeps one provenance ledger per work — what is AI-made vs human-made, which tools were used, an honest estimate of the AI share — and runs a pre-publish disclosure check and a post-publish verification for each platform.

## Hard rules

1. Disclose what must be disclosed, before publishing.
2. Never hide, remove, or evade AI disclosure or detection. This skill contains no evasion steps.
3. Estimate the AI share honestly; if unknown, say so.
4. Verify the platform's current rules on its official help page before publishing — rules change.
