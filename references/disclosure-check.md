# 公開前チェックリスト

作品を出す前に、このチェックリストを1つずつ確認する。すべてにチェックが入ってから公開する。

## 全プラットフォーム共通

- [ ] 台帳（provenance-ledger.md）に、工程ごとの出所とAIの割合を記録した
- [ ] AIの割合の見積もりに根拠がある（根拠なしの数字は使っていない）
- [ ] 出すプラットフォームの申告方法を `references/platform-rules.md` で確認した
- [ ] プラットフォームの公式ヘルプで、最新の申告ルールを確認した
- [ ] 申告の文言・タグ・設定を決めた
- [ ] 申告を公開前に設定した（公開後の「あとで申告」はしない）

## 文章の作品（小説・記事）

- [ ] 不可視文字・ゼロ幅文字が入っていないか確認した
  - 確認方法：文章をテキストエディタに貼り、不可視文字を表示する設定で確認する。または、文字数を数えて想定と合うか確認する。
  - 確認できない場合は「未確認」と台帳に書く
- [ ] AIの下書きをそのまま出していない（自分の言葉への書き直しが済んでいる）
- [ ] 引用がある場合、出典を明記した（引用は50文字以内を目安に）

## 画像の作品（表紙・挿絵・Etsyアート）

- [ ] 画像の生成・編集・合成のどこまでAIが関わったかを台帳に書いた
- [ ] 生成ツールが付与する透かし・Content Credentialsの有無を確認した（確認できない場合は「未確認」と書く）
- [ ] 他人の作品・写真を無断で使っていない
- [ ] Etsyの場合：説明文にAI利用の明記を入れた

## 動画の作品（YouTube・ショート動画）

- [ ] YouTube Studioの「改変または合成されたコンテンツ」の申告要否を確認した
- [ ] ナレーションがAI音声（TTS）の場合、その旨を台帳に記録した
- [ ] 動画内の画像・映像の出所を台帳に記録した
- [ ] 他人の動画・音楽・画像を無断で使っていない

## 音声の作品（ナレーション・楽曲）

- [ ] ナレーションがAI音声の場合、その旨を台帳に記録した
- [ ] 楽曲がAI生成の場合、その旨を台帳に記録した
- [ ] 他人の声をクローンしていない（他人の声のクローンはしない）

## 公開後の確認

- [ ] 公開ページを開き、申告が表示されていることを自分の目で確認した
- [ ] 表示されていなければ、設定し直すか、プラットフォームの表示条件を確認した
- [ ] 申告内容を台帳に記録した（何を・どこに・いつ申告したか）

## 申告の更新が必要なとき

- 作品を書き直した・画像を差し替えた・動画を編集し直したときは、台帳を更新する。
- AIの割合が変わった場合は、割合を見積もり直す。
- 申告の種類が変わる場合は、申告も更新する。
- 更新したら、公開ページで表示を再確認する。
