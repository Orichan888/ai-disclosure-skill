# プロヴェナンス台帳の型と記入例

台帳は1プロジェクトにつき1ファイル。人間が読めるMarkdownで書く。個人情報（アカウント情報・本名・住所など）は書かない。

## 型

```markdown
# プロヴェナンス台帳 — [作品名]

## 作品情報
- 作品名：
- 出す場所（プラットフォーム）：
- 公開予定日：
- 最終更新日：

## 工程ごとの出所
| 工程 | 担当 | 使ったツール | 備考 |
|---|---|---|---|
| 下書き | AI生成 | （例：Muse） |  |
| 仕上げ・書き直し | 人間作成 |  |  |
| 表紙・挿絵 | AI生成＋人間仕上げ | （例：Grok、SDXL） |  |
| ナレーション | AI生成（TTS） | （例：TTS） | 声の確認は人間が行う |

## AIの割合の見積もり
- 全体の見積もり：[例：本文の約70%がAI下書き。ただし人間が全面書き直し済み]
- 根拠：[例：下書きはAI、段落の組み立てと表現は人間が書き直したため]
- 不明な部分：[例：なし／画像の生成比率は不明]

## 申告の記録
| 日付 | プラットフォーム | 申告内容 | 確認 |
|---|---|---|---|
| 2026-11-24 | カクヨム | AI本文利用 | 公開ページで表示を確認済み |

## 変更履歴
- 2026-11-21：初版作成
- （書き直し・差し替えのたびに追記）
```

## 記入例1：小説（カクヨム）

```markdown
# プロヴェナンス台帳 — 地底王国の転生王子 第1巻

## 作品情報
- 作品名：地底王国の転生王子、世界をおいしく革命します 第1巻
- 出す場所（プラットフォーム）：カクヨム
- 公開予定日：全10巻書き終えてから（2026-11-21時点で延期）
- 最終更新日：2026-11-21

## 工程ごとの出所
| 工程 | 担当 | 使ったツール | 備考 |
|---|---|---|---|
| 下書き（第1巻14話） | AI生成 | Muse | ChatGPTとの共同作業から引き継ぎ |
| 人間らしい書き直し | 人間作成（AIが支援） | Muse | 三つ並び・副詞の繰り返し・段落末のまとめを除去 |
| バイブル・設定 | AI生成＋人間判断 | Muse | 矛盾点の決定は人間（香織）の承認つき |

## AIの割合の見積もり
- 全体の見積もり：本文の多くがAI下書きをもとにしているため、現時点では「AI本文利用」が該当
- 根拠：下書きはAI、書き直しは人間の言葉への書き換え。ただし土台の文章がAIのため、50%以上のAI関与と見積もる
- 不明な部分：なし

## 申告の記録
| 日付 | プラットフォーム | 申告内容 | 確認 |
|---|---|---|---|
| （未公開） | カクヨム | AI本文利用（予定） | 公開時に設定し、表示を確認する |

## 変更履歴
- 2026-11-21：初版作成
```

## 記入例2：Etsy出品（デジタルアート）

```markdown
# プロヴェナンス台帳 — 月女神オラクルデッキ（44枚）

## 作品情報
- 作品名：月女神オラクルデッキ＋ガイドブック
- 出す場所（プラットフォーム）：Etsy
- 公開予定日：未定
- 最終更新日：2026-11-21

## 工程ごとの出所
| 工程 | 担当 | 使ったツール | 備考 |
|---|---|---|---|
| カード画像（12枚） | AI生成 | Grok | 月女神シリーズ。顔立ち・構図は人間が確認 |
| カード画像（残り32枚） | AI生成（予定） | SDXL（Colab） |  |
| カードの意味・キーワード | 人間作成（AIが支援） | Muse | 44枚分の意味とキーワード |
| ガイドブック | 人間作成（AIが支援） | Muse |  |
| 商品説明文 | 人間作成（AIが支援） | Muse | AI利用の開示を含む |

## AIの割合の見積もり
- 全体の見積もり：画像はAI生成、文章は人間作成＋AI支援
- 根拠：画像は生成AI、文章は人間が内容を決めてAIが下書き
- 不明な部分：なし

## 申告の記録
| 日付 | プラットフォーム | 申告内容 | 確認 |
|---|---|---|---|
| （未出品） | Etsy | 説明文にAI生成の明記（予定） | 出品時に設定し、表示を確認する |
```

## 書き方の注意

- 「AI生成」「AI補助」「人間作成」の3つに分けて書く。「AI補助」は、AIが下書き・推敲を手伝い、最終判断を人間がしたもの。
- 割合は「約○%」と見積もり、根拠も一緒に書く。根拠なしの数字は書かない。
- 書き直し・差し替えをしたら、見積もりを更新して変更履歴に追記する。
- 台帳は作品と一緒に保管する。公開後に申告の種類が変わる場合は、申告と台帳の両方を更新する。
